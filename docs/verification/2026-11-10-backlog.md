Исходное состояние: две записи FINDINGS — задержка нового хода шлюза на Windows и
незавершённый базовый замер `pii_benchmark` для слоёв 1–4. IDEAS уже содержал только шапку.
Проверен код `158e615`; исходники, пороги скорости и проверки отправляемых данных не менялись.

## Скорость шлюза

- Отдельный новый ход: p50 228 мс, p95 304 мс, прямой запрос 9 мс;
  добавка **295 мс**, прежний сохранённый результат — 334 мс.
- Полный `tests/test_gateway_speed.py -m integration -n 0 -rP`: **6 passed**, 130,08 с.
  Добавка нового хода — **280 мс**; повторённое тело Anthropic — 208 мс, Responses — 198 мс,
  повторённое тело в чате с 20 000 сущностей — 240 мс. Новые 100 000 знаков — 1,829 с.
  Первый текст пришёл за 316 мс, до завершения ответа провайдера, с паузой 1 с.
- Отдельный новый ход с замерами функций: **1 passed**, 22,95 с; добавка **250 мс**.
  Обёртки измеряли только время, возвращали исходный результат и не меняли проверки теста.

Профиль сорока новых ходов после прогрева (среднее время, мс; CPU — время текущего потока):

Строки вложены друг в друга, складывать их нельзя; время потока Windows имеет дискретность.
Основная стоимость — работа CPU при подготовке и сохранении состояния, а не ожидание диска.
Перед полным прогоном загрузка CPU была 12%, после — 5%; отдельные снимки во время него — 29–33%.
На том же коде прежнее превышение не повторилось в трёх прогонах. Это подтверждает зависимость
порогового замера от условий запуска; точную причину старого выброса без профиля того запуска
установить нельзя. Оснований менять алгоритм или порог 300 мс по полученным данным нет.
Проверка новых блоков и повторная проверка SEC-2 в egress сохранены.

файла окружения внутри процесса; его значение в аргументы и вывод не передавалось.

`redmadrobot-rnd/pii_benchmark` @ `f77ea831274daf980cc45c61a93c226be9d978d6`,

- Два запуска быстрого набора: каждый **2884 passed, 2 skipped**, 68,46 и 92,85 с.
  Пропущены проверки серверного периметра без `CLEANER_SERVER_GUARD` и `CLEANER_PERIMETER_CONFIG`.

  проверены отдельно с `-n 0`: **4 passed**, 3,12 с; вызовы заняли 0,30–0,87 с вместо 1,00–1,09 с.
  Постоянное превышение секунды у отдельного теста не воспроизвелось.
- Проверка сохранённого паспорта: 2139 примеров, оба набора слоёв; `drops`, `unchecked` и `warnings`
  пусты, все метрики совпадают с новым baseline.
- `FINDINGS.md` и `IDEAS.md` точно равны результатам канонических `findings_header` и `ideas_header`
  из общего генератора шапок, включая завершающую пустую строку. Обе исходные записи удалены;
  отклонённых задач в этой партии нет.
